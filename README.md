## 🛠️ How to Use the Repository

**Clone the Repository**:
```bash
   git clone https://github.com/CO-in-adverserial-training/SolvingCO.git
   cd SolvingCO/Codes
```
**Run Experiments**:
```bash
   pyhton main.py --root_path absolute/result/root/path --attack SORA --seed 42
```
Explore experiments or results and run the notebooks.
